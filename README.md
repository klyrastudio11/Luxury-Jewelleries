# Klyra Studio

A premium luxury jewellery website built with Next.js, TypeScript, Tailwind CSS, and a polished editorial experience.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## Notes

The storefront includes a luxury homepage, curated collections, product experience, and private admin login route. Supabase wiring is prepared in the app for future database and authentication integration.
